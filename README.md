# MiniMax Music 3 Prompt Writing Skill

Prompt-writing skill for **MiniMax Music 3 song generation**: the caption + lyrics method, with a genre router and a large template library.

## Files

- [`SKILL.md`](SKILL.md) - the skill itself
- [`references/prompting-guide-full.md`](references/prompting-guide-full.md) - full prompting guide
- [`library/`](library/) - genre indexes and prompt templates

## Install (Hermes Agent)

Copy this folder into your Hermes skills directory:

```
~/AppData/Local/hermes/skills/creative/minimax-music3-prompt-writing
```
